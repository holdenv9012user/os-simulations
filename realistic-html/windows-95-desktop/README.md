# Windows 95 desktop

Open `index.html` directly in a browser. No server or dependencies are needed.

A BIOS memory check leads to a Windows 95-inspired cloudy startup screen and animated loading strip, then a teal desktop. The boot takes about six seconds; Skip boot opens the desktop immediately.

- Double-click My Computer, Network Neighborhood, or Recycle Bin. Touch users can tap once; keyboard users can focus an icon and press Enter.
- Drag title bars, minimize or maximize windows, and restore them from the taskbar.
- Explore Start, Programs, Control Panel, Help, and Run. Run accepts `notepad`, `explorer`, `control`, and `command`.
- Notepad accepts text; Control Panel changes the desktop color. Sample files and drives are simulated. Menu-bar labels inside windows are decorative.
- Choose Start → Shut Down → Yes to see “It is now safe to turn off your computer.” Move the pointer or press Tab to reveal Power on. The shutdown dialog also supports Restart.

All graphics are made with HTML and CSS. This is an unofficial visual recreation, not an operating system. It does not access drives or change device settings; Notepad text is not saved to disk.
