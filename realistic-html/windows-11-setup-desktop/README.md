# Windows 11 — setup to desktop

Download **windows-11.html** and open it directly in a browser. Everything is embedded in that single file; there are no external assets or dependencies.

Go through language selection, the product-key skip, Home/Pro edition, a simulation acknowledgment, custom installation, a sample drive, installation progress, and a restart. First-run setup then asks for region, keyboard, a local display name, and preview privacy preferences before opening the desktop. Installation takes about 10 seconds; the full experience depends on how quickly you move through the screens.

The desktop includes:

- A searchable Start menu and centered taskbar.
- Draggable, minimizable, maximizable, closable app windows; taskbar buttons restore apps.
- File Explorer with sample folders and a virtual drive, plus an empty Recycle Bin.
- Notepad with editable text retained when its window is closed and reopened during the same page session.
- A working arithmetic calculator.
- Settings with desktop colors and the setup choices you selected.
- A browser-style local welcome page (not a web browser).
- Shut down and Power on, plus optional fullscreen.

Double-click desktop icons, single-click Start/taskbar apps, or tap icons on touch screens. Keyboard users can focus buttons and press Enter. Reload to start setup over. Reduced-motion preferences disable spinner animation.

This is an unofficial visual simulation, not Windows or an emulator. It uses no real disk, product key, account login, network configuration, or system permissions. All setup settings and notes remain in memory and are cleared when the page reloads. No actual Microsoft license agreement is presented or accepted.
