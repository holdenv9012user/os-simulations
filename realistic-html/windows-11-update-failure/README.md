# Windows 11 update failure

Open `index.html` directly in a browser. This self-contained simulation slowly advances “Working on updates” to 30%, displays a restart and Windows logo, then stays on “Something didn’t go as planned. No need to worry—undoing changes.” with a looping spinner.

The complete sequence takes about 26 seconds. Move the pointer to reveal Skip to failure, Replay update, and Fullscreen. Press Escape to leave fullscreen. Reduced-motion preferences disable the spinner animation.

This is only a visual simulation; it does not install updates, restart the device, or change files or settings.
