# Windows 11 static recovery screen

Open `index.html` in a browser. A Windows boot logo appears for 0.65 seconds, then the blue “Recovery — Your PC/Device needs to be repaired” screen remains indefinitely.

The displayed recovery key instructions are decorative. No recovery menus open and no system settings change. Move the pointer to show the fullscreen control; Escape exits fullscreen normally. Reload the page to replay the brief boot logo.
