# MS-DOS boot failure

Open `index.html` in a browser. MS-DOS startup commands appear, the screen clears to only a blinking cursor for less than a second, then a simulated reboot ends at “An operating system was not found.” The sequence takes about six seconds and remains on the final error.

Move the pointer to reveal Replay boot, Skip to error, and Fullscreen. Escape exits fullscreen. The final “Press any key to restart” text is decorative; use Replay boot to restart the simulation. No commands run and no device settings or files are changed. No external assets are required.
