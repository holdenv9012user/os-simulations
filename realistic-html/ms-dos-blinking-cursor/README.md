# MS-DOS blinking cursor

Open `index.html` in a browser. After about four seconds of simulated MS-DOS startup text, the screen clears and shows only a blinking cursor in the upper-left corner, indefinitely. There is no prompt, input, reboot, or overlay. Reload the page to replay the boot sequence.

The page is self-contained and does not execute DOS commands. With reduced motion enabled, the cursor remains visible without blinking.
