# Windows 11 installer error loop

Open `index.html` in a browser. Choose Next, Install now, and either installation type. Installation progresses to exactly 45%, then displays:

> The file 'cmd.exe' was unable to be made

Click OK to restart the installer from the language selection screen. Every installation attempt fails at the same point. The installation progress takes about ten seconds.

Fullscreen is optional; Escape exits fullscreen. This is a self-contained visual simulation using a simulated drive. It does not install Windows, access disks, or change files.
