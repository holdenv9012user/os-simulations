# Windows 10 profile error

Open `index.html` in a browser. After a brief Windows 10 boot logo and spinning dots, the login screen appears with a blue Windows-inspired background and a User account.

Click **Sign in** to briefly show Welcome, then “The User Profile Service service failed the sign-in. User profile cannot be loaded.” The error stays until you click **OK**, which returns to sign-in. Each attempt produces the same error.

Move the pointer to reveal Skip boot, Replay boot, and Fullscreen. Escape exits fullscreen. This standalone visual simulation uses no external assets, requests no password, and does not access accounts or change your computer.
