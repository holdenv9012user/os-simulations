# Windows 11 boot and recovery simulation

Open `index.html` in a browser. No server, downloads, or dependencies are required.

The sequence takes about 14 seconds: Windows logo → Preparing Automatic Repair → Diagnosing your PC → Automatic Repair failure. Select **Advanced options → Troubleshoot → Advanced options** to explore the recovery tools. Startup Repair runs a second repair animation and ends with the repair-failure screen and SrtTrail.txt log path.

Move the pointer to reveal **Skip to recovery**, **Replay boot**, and **Fullscreen** controls. Escape exits fullscreen. Restart and Continue replay the boot sequence; shutdown shows a black screen that can be exited with Replay boot. Recovery tools are interactive previews and never modify files, execute commands, restart the computer, or change system settings.
